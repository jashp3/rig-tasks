Direction 3 — Threads

Thesis: a task manager is a stack of loose thoughts you settle one at a time — each thing you capture is a note addressed to yourself, “done” means the loop is closed, not that a box is ticked. It optimises for zero taxonomy and for a feeling of quiet as each thing settles — and at the expense of seeing the shape of a week, because a conversation has no shape; you can only ever see the next thing.

There is no list, no project and no date anywhere in this one. Tap a note to open it — you can add lines to it while you think, which is how a two-second capture stays honest a week later. Resolving a note dissolves it into the settled line. The laptop shows the same river with the open loops gathered on the right.
